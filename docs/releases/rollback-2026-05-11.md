## 修复记录

### Bug 修复：API 返回格式不兼容

**问题描述**:
- 前端 `api.ts` 期望后端返回 `{success: true, data: [...]}`
- 后端 `server.js` 直接返回数组 `[...]`
- 导致前端无法正确解析数据，显示"暂无游戏"

**修复方案**:
修改 `src/utils/api.ts` 中的 `request` 函数，添加数组格式兼容处理：

```typescript
const data = await response.json()

// 兼容处理：如果返回的是数组而不是 ApiResponse 对象
if (Array.isArray(data)) {
  return { success: true, data: data as T }
}

return data as ApiResponse<T>
```

**修复文件**:
- `src/utils/api.ts` - 添加数组格式兼容逻辑

**验证方法**:
1. 访问 https://gamexxxyx.pages.dev
2. 确认游戏列表正常显示
3. 检查浏览器控制台无错误
